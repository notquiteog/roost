    Rewind
    
  
    
    Put files back to how they were before a turn. This undoes that turn and every
    one after it — undoing one in the middle would leave a state that never existed.
  
    
  
    
    Only the agent's own file edits are recorded. Anything a shell command wrote is
    not covered, and cannot be: snapshotting the whole filesystem before every
    command is not something anyone wants.
